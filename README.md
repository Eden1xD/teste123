# Game Lobby App

Este projeto é uma estrutura inicial para uma aplicação web com lobby, partida, ranking e perfil.

## Estrutura

```text
server/
  server.js
  game.js
  rooms.js
  database.js
public/
  index.html
  game.html
  ranking.html
  profile.html
  css/
    style.css
    game.css
    responsive.css
  js/
    app.js
    lobby.js
    game.js
    ranking.js
    profile.js
  assets/
    images/
    sounds/
```

## Como iniciar

```bash
npm install
npm start
```

Depois, abra o navegador em `http://localhost:3000`.
